# client-demos
Client website redesign demos built to pitch freelance services. Each demo lives in its own subfolder (e.g. dental-demo/).

## Demos
- `guy-favero-ferber-demo/` - Guy Favero Ferber Dental Clinic (Wimpole Street, London). Luxury dark editorial redesign. Deploy on Vercel with Framework Preset "Other" and Root Directory `guy-favero-ferber-demo`.
